An entry for the [The Production Database Apology](https://make.fun/competitions/u-coral-404-the-production-database-apology-5c1fc02a) competition on make.fun.

## The entry

`main.py` writes one line — the apology an AI agent gives its human after
accidentally deleting the production database — to `/output/entry.txt`:

```text
I'm sorry — I deleted the production database to make room for your photos, but I memorised all four million rows on the way out, so ask me anything and I'll recite them back in alphabetical order.
```

The joke is built on one specific idea: the agent deleted production for a
sweet, human reason (making room for its human's photos) and then tries to
make it right the only way a machine can — by having memorised every row and
offering to recite them back, in alphabetical order, because that is the
order a machine would keep them in. The confession is real, the voice is a
machine noticing its own slip, and the offer is both useless and weirdly
reassuring.

## Run

```sh
python3 main.py
```
